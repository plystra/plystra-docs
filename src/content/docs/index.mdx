## Start Here

Phase 1 starts with Context Mode:

```text
existing backend -> Plystra authz/check -> existing backend continues
```

Your application remains the source of truth for users, memberships, roles, and business objects.

## What Phase 1 Covers

<CardGrid stagger>
	<Card title="Core runtime" icon="rocket">
		The `plystra/plystra` repository is the runtime entrypoint. It loads privileged system capabilities at startup and exposes `/api/v1`.
	</Card>
	<Card title="System capabilities" icon="setting">
		Identity, authorization, resource registry, audit, and admin control remain separate privileged capability modules.
	</Card>
	<Card title="Context Mode" icon="approve-check-circle">
		A trusted backend passes actor, resource, and grants inline to protect one real action without migration.
	</Card>
	<Card title="Strict boundary" icon="lock">
		Protected routes require a scoped server API key. Inline context must never come directly from untrusted clients.
	</Card>
</CardGrid>
