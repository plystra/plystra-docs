Plystra Core v1.0 提供稳定的自托管身份与授权核心。

## 重点能力

- `User -> UserMember -> Member -> Space` 身份链。
- explainable authz engine。
- `self`、`group`、`group_tree`、`space` scope。
- Resource Registry。
- Ent schema 和 versioned migrations。
- 追加式 audit logs。
- Bearer session 保护 Core 管理 API。
- Docker Compose 与 CLI 运维入口。

## 升级提醒

升级前请阅读迁移指南，并运行 release readiness checklist。
